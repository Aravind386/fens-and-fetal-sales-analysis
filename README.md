
# Ferns and Petals (FNP) Sales Analysis Dashboard

## 📌 Project Overview

Developed a sales analysis dashboard for Ferns and Petals (FNP) to analyze revenue, order performance, product categories, customer spending, delivery time, and occasion-based sales trends.

The project uses sales data to identify high-performing products, revenue-generating categories, monthly order trends, and cities with the highest order volumes.

## 🎯 Project Objectives

- Analyze total revenue and order performance.
- Understand average customer spending and delivery time.
- Evaluate monthly sales performance.
- Identify the top 10 products by revenue.
- Compare revenue across product categories.
- Analyze sales performance by occasion.
- Identify the top 10 cities by number of orders.
- Understand product and customer purchasing trends.
