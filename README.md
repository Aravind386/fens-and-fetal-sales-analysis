
# 💐 Ferns and Petals (FNP) Sales Analysis Dashboard

### 📊 Sales Performance | Customer Insights | Occasion-Based Analysis

An interactive sales analysis project focused on understanding Ferns and Petals (FNP) business performance through revenue analysis, customer spending, product performance, delivery timelines, and occasion-based sales trends.

The project aims to uncover actionable insights that can help improve sales strategies, product planning, delivery performance, and customer satisfaction.

---

## 📌 Project Overview

Ferns and Petals (FNP) specialises in delivering gifts for occasions such as birthdays, anniversaries, Valentine's Day, Diwali, Holi, and Raksha Bandhan.

This project analyses the company's 2023 sales dataset to understand revenue trends, customer purchasing behaviour, product performance, and delivery timelines.

Using data analysis and dashboard visualisations, the project answers key business questions and provides insights to support data-driven decision-making.

---

## 🎯 Project Objectives

- Identify total revenue and overall order performance.
- Analyse average customer spending.
- Evaluate average order-to-delivery time.
- Compare monthly sales performance during 2023.
- Identify the highest revenue-generating products and categories.
- Track sales performance of the top five products.
- Identify the top 10 cities by number of orders.
- Analyse the relationship between order quantity and delivery time.
- Compare revenue across different occasions.
- Identify popular products for specific occasions.
